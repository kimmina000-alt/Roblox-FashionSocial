# 겨울 첫눈 프레임 (D-1874)

`python draw.py` draws the winter attendance event's frame `winter2026` in the game's strip geometry
(PhotoRender.newStrip: 4:3 cells, 0.35 gaps, 1.4 footer) with a margin for the pieces past the edge:
snow-lace scallops, ice gradient, snow dots, snowflakes, a snowman at the bottom left, "OHU" in the footer.
Writes winter_2x2.png / winter_1x4.png and info.json (PhotoConfig `art[layout]` rectangles).
Draft art: if the user sends their own drawing, cut it out like tools/art/opening_frame instead.
