# 안무 포즈 글 비교 도구 (D-1863)

원본 안무 영상과 게임 속 안무를 0.05초 단위로 같은 방식으로 읽고, 포즈를 한국어 문장으로 적은 다음,
다른 곳만 골라 줍니다. 사용자가 손으로 적던 메모("0:53 왼손 안쪽으로 꺾기")를 먼저 기계가 뽑고,
애매한 곳은 그림 시트로 눈으로 확인합니다.

## 흐름

1. **원본 → 포즈** (`pose_video.py`): MediaPipe Pose(3D 점 33개) + 손 모델(손바닥 방향, 손목 꺾기).
   centercut 폴더를 주면 centercut이 따라간 그 멤버(옷 색 + seeds, `followed.json`에 캐시)를 따라갑니다.
   ```
   python tools/choreo/describe/pose_video.py "D:/Roblox/영상/TWS_CallMyName_lAf01WUYtf8.mp4" --off -1.25 --cc "D:/Roblox/영상/TWS_CallMyName_centercut" --out tws_v.json
   ```
   `--off` = 곡 시간 − 영상 시간 (첫 조각의 `from`을 빼면 됨: TWS는 `from = 1.25` → `--off -1.25`).
   3분 곡에 약 8분이 걸립니다(0.05초 간격).
2. **게임 → 포즈** (`pose_record.lua` + `pose_log.py`): Play 중 Client에서 LocalScript로 넣으면
   곡을 틀고 🎵 안무를 켠 다음, 관절 점을 0.05초마다 Studio 로그 파일에 찍습니다(MCP 시간 제한 없음,
   출력이 대화에 들어오지 않음). 넣는 방법은 `pose_record.lua` 맨 위 주석 참고.
   ```
   python tools/choreo/describe/pose_log.py tws --out tws_g.json
   ```
3. **글로 쓰기 / 비교** (`pose_text.py`):
   ```
   python tools/choreo/describe/pose_text.py describe tws_v.json --out 원본_포즈.txt
   python tools/choreo/describe/pose_text.py compare tws_v.json tws_g.json --sheet sheets --out 차이.txt
   ```
4. **그림 시트** (`pose_sheet.py`, compare `--sheet`가 차이마다 자동으로 만듦): 위 = 원본 영상(읽은 점),
   가운데 = 게임 포즈 막대 인형, 아래 = 원본의 3D 점을 게임과 같은 방식으로 그린 것. 0.1초 간격.

## 읽는 것

| 부위 | 상태 (describe) | 비교 기준 (compare) |
|---|---|---|
| 팔 | 방향(위·앞·옆·아래·뒤·안쪽) + 쭉 뻗음 / 굽힘 / 직각(위팔·아래팔 방향) / 접음 | 어깨→손목 방향 50°+ 또는 팔꿈치 55°+ 차이 |
| 손목 | 안쪽으로 꺾음(손바닥 쪽) / 밖으로 꺾음(손등 쪽) / 일자 | 35°+ 차이이고 한쪽이 35°+ 꺾임 |
| 손 위치 | 얼굴 · 정수리 · 귀 · 같은 쪽 어깨 · 반대 어깨 · 가슴 · 배 · 옆구리 · 양손 모음 · 반대팔 위 · 바닥 | 원본의 위치가 게임에 없음 |
| 허리 | 숙임(30°+) / 깊이 숙임(60°+) / 뒤로 젖힘 / 옆 기울임 | 22°+ (옆 15°+) |
| 몸 방향 | 정면 / 측면 / 뒤 | 50°+ |
| 고개 | 좌우로 봄 / 숙임 / 듦 / 꺾음 | 30° / 22° / 15° |
| 다리 | 무릎 꿇음(왼/오른/양) / 앉음 / 무릎 굽힘 / 공중 / 발 듦 / 앞으로 차기 / 다리 벌림 | 범주가 다름 |
| 동작 ★ | 회전(방향, 반 바퀴/한 바퀴, 걸린 시간) · 점프(뜬 시간, 높이) · 팔 크게 돌리기 · 손목 돌리기 · 반바퀴씩 좌우 · 흔들기/털기 · 어깨 들썩 · 가슴 튕기기 · 손뼉 · 이동/제자리 스텝 | 원본에 있는데 게임에 없음, 게임에만 있는 회전/점프 |
| 품질 | | 멈춤(원본은 움직이는데 게임이 멈춤), 회전 버벅(도는 중 멈칫/역회전), 타이밍(4초마다 게임이 몇 초 늦거나 빠름) |

모든 길이는 몸통 길이(어깨 가운데 ↔ 골반 가운데) 단위라 영상과 게임의 크기 차이가 없습니다.
좌우는 춤추는 사람 자신의 좌우입니다. compare는 거울 여부를 팔 일치도로 스스로 고릅니다(`--mirror auto`).

## 한계

- 영상의 높이(점프, 무릎 꿇기)와 이동은 그림에서 읽으므로 카메라가 움직이면 틀립니다. 앞뒤 이동은 대략입니다.
- 손목 비틀기, 손가락은 손 모델이 손을 잡은 프레임에서만 믿을 만합니다.
- 꽃받침, 볼 터치, 개다리춤처럼 이름 있는 동작은 문장 조합으로만 나옵니다: 시트를 보고 이름을 붙입니다.
- 멤버가 가려진 구간은 비교하지 않습니다(인식률이 맨 위에 나옴).
- 카메라 쪽으로 숙이는 허리는 원본에서 얕게 읽힙니다(부기우기 1:18-1:19는 그림으로 보면 깊이 숙였는데 18-34°로 읽힘). "원본 바로 → 게임 숙임"은 그림으로 확인하기 전에는 고치지 않습니다.
- 무대 영상(카메라 컷 · 멤버가 자주 바뀜)은 연습 영상보다 거짓 경보가 많습니다. 부기우기 · 언빌리버블(2026-11-19): 허리 · 멈춤 후보 15곳 중 1곳만 진짜.
