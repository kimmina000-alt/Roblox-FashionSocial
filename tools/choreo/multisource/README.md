# multisource: 한 사람을 여러 영상에서 이어 붙여 안무 클립 만들기 (D-1960)

aespa 「Lemonade」 v3에서 쓴 방법이에요. 연습 영상 하나로는 한 멤버가 곡 내내 잘 보이지 않을 때, 같은 멤버의 무대 직캠 여러 개와 연습 영상을 구간마다 골라 씁니다. 앞뒤 클립은 2초씩 겹치게 만들고, 게임에서는 `blend`로 그 2초를 섞어요. 같은 사람이 같은 순간에 추는 동작끼리 섞여서 이음새가 거의 보이지 않아요.

작업 폴더(큰 파일): `D:\Roblox\영상\_work\lemonade_full` (C 드라이브는 공간이 없어요). 스크립트 안의 경로와 구간은 레모네이드 기준이라, 다른 곡은 복사해서 바꿔 쓰세요.

1. **영상 찾기** — `yt-dlp "ytsearch12:<곡> fancam"`. 직캠은 세로라서 `-f "bv*[width<=1080]+ba"`로 받아요(`height<=1080`이면 480p가 와요).
2. **시간 맞추기** — `al7.py <영상id>...`: 화음(chroma) 특징으로 2초 창마다 "영상 몇 초 = 곡 몇 초"를 찾아요. 소리 세기나 박자 특징은 반복되는 비트 때문에 틀려요. 무대 버전은 편곡이 잘린 경우가 있어서(SBS 레모네이드는 9초 + 3초가 빠짐) 구간마다 따로 맞춰요. 기준은 연습 영상 소리예요(곡 = 연습 영상 - 1.08초).
3. **사람 추적** — centercut으로 `--no-render --exclude-dark 0`만 돌려 `tracks.json`을 만들어요.
4. **구간별로 어떤 영상을 쓸지** — `score.py`(머리·발이 화면 안, 앞을 가리는 사람)로 대강 보고, 문제 구간은 `cmp.py <곡 시작> <곡 끝> <간격> <이름>`으로 영상들의 같은 순간을 나란히 놓고 직접 골라요. 자동 점수만으로 고르면 지나가는 사람을 놓쳐요.
5. **클립 만들기** — `mkclips3.py`: 클립마다 사람 지정(seeds)을 0.5초마다, 옷 색깔이 기준 사람과 가장 비슷하고 화면 가운데에 있는 사람으로 정해요. 연습 영상 멤버는 예전 컷 편집의 번호(예: 90008)를 직접 넣어요. `render_final.py <번호>...`로 렌더링해요. 클립 폴더를 다시 쓸 때는 다른 영상의 `tracks.json`이 남아 있지 않은지 확인하세요(전부 흐리게 나와요). 무대 영상은 `ffmpeg -vf hflip`으로 기존 안무와 같은 미러 방향으로 바꿔요.
6. **확인** — 클립마다 2fps 미리보기로 주인공이 끝까지 같은 사람인지 봐요. 그 뒤 Studio Play로 곡 전체 떨림을 재요(play_record 방식).
