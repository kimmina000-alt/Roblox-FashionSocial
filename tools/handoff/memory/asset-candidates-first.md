Before inserting/placing any Roblox Creator Store (Toolbox) asset into the game, first report a shortlist of candidate items (name, creator, why) to the user and wait for their pick. The one exception was the 2026-10-22 cherry trees in the hanok village, placed temporarily as a well-reviewed pick.

**Why:** the user wants to choose the look of art assets themselves (user, 2026-10-22).

**How to apply:** search_asset → pick 3–5 candidates (thumbnail/creator/popularity) → report in Korean → insert only after the user chooses. Related: [[testing-mobile-2p]].
