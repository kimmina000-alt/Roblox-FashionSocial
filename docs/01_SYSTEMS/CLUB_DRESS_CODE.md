# 클럽 드레스코드 이벤트 (입뺀) — 기획서

기준일: 2026-10-22
상태: **기획 확정, 구현은 게임 완성 후 첫 시즌 이벤트를 만들 때** (가드 캐릭터도 그때 제작)
관련: `CLUB.md`, `ECONOMY.md`, `CAFE.md` §9(알바), D-101

## 1. 한 줄 요약
시즌 이벤트 기간(핼로윈, 크리스마스 등)에만 클럽 입구에 가드가 서서 **그날의 색(드레스코드)이 들어간 아이템을 입은 사람만** 들여보낸다. 안 맞으면 입뺀(튕겨 나감). 이벤트가 아닐 때는 누구나 입장.

## 2. 이벤트 기간과 색
- **시간대가 아니라 시즌 기간** 단위. 자주 하지 않는다.
  - 예: 크리스마스 = 12월 23일 ~ 12월 25일, 핼로윈 = 10월 말 며칠.
- 기간은 **한국 시간(KST)** 기준으로 시작일 0시 ~ 종료일 24시.
- 색은 이벤트마다 운영자(사용자)가 고른다. 후보 예: RED, BLACK, WHITE, PINK, BLUE, ORANGE, GREEN.
  - 핼로윈 → 주황(ORANGE), 크리스마스 → 레드·그린.
- 색이 두 개 이상이면 **그중 하나만 입어도 통과**.
- 설정은 코드 한 곳(예: `ClubDressConfig.lua`)에 시즌 목록으로 둔다: 이름, 시작일, 종료일, 색 목록, 공지 문구.

## 3. 공지
- 이벤트 기간에는 **클럽 간판 근처**에 "오늘의 드레스코드: RED" 같은 공지를 띄운다(색 이름 + 색 견본).
- 이벤트가 아닐 때는 공지를 숨긴다.

## 4. 판정 방법 — 착용 아이템 읽기
- 서버가 캐릭터가 입고 있는 아이템 번호 전체(액세서리, 레이어드 옷, 클래식 셔츠·바지 등)를 한 번에 읽는다. 보통 5~20개.
- 로블록스 아이템에는 "색" 정보가 따로 없고, 남이 만든 아이템의 실제 텍스처 색은 읽을 수 없다. 그래서:
  1. **1차: 아이템 이름이나 설명에 색 단어가 있으면 통과.**
     - RED 예: Red, 레드, 빨간, 빨강, Crimson, Scarlet (+ Cherry, Ruby, Burgundy 등 비슷한 말 목록은 색마다 설정에 둔다)
     - 아이템 정보는 한 번 읽으면 저장해 두고 다시 묻지 않는다(서버 부담 적음).
  2. **2차: 드레스코드 아이템 뽑기**(§6)로 받은 아이템은 무조건 통과.
- 한계(알고 진행): 빨간 옷인데 이름에 색이 없으면 탈락, 이름에만 Red가 있으면 통과할 수 있다. 이름 판정이 안 되는 사람은 뽑기로 들어올 수 있다.

## 5. 입장 연출 (입구 가드)
1. 들어가려고 하면 **입구 옆에 서 있는 가드 앞**으로 가게 된다(입구 선에 보이지 않는 막이 있고, 가드 앞 검사 지점으로 안내).
2. 가드가 **한 명씩** 드레스코드를 확인한다(잠깐 확인하는 동작/시간).
3. 통과 → 가드 말풍선 "들어가십시오." 또는 "즐거운 시간 보내십시오." 같은 환영 인사 → 입장.
4. 실패 → "드레스 코드가 맞지 않습니다." 또는 "당신은 입뺀." 문구 → 가드 앞 검사 자리(또는 클럽 입구 선)에서 **뒤로 3 스터드 튕겨 나감**. 화면에 "○○색 아이템이 필요해요" 안내와 뽑기 버튼(§6).
- 한 번 통과한 사람은 이벤트 기간 동안 다시 들어올 때도 같은 검사를 받는다(지금 입은 옷 기준).

## 6. 드레스코드 아이템 뽑기 (1코인)
- 이벤트 기간에 입구 근처에 "드레스코드 아이템 뽑기 (1코인)".
- 서버가 카탈로그에서 그날 색(예: "red")으로 검색해 **이름에 색 단어가 있는 액세서리나 옷 중 하나를 사람마다 랜덤으로** 골라 입혀 준다 → 판정 통과가 보장된다.
- 마음에 안 들면 **1코인 더 내고 다시 뽑기** 가능.
- 게임 안에서 입혀 주는 것(기존 입어 보기 기능)이라 **이 서버에서만 보이고 진짜 로블록스 아이템을 소유하는 것은 아니다.** 안내 문구에 표시.
- 코인 쓰는 곳(소비처)이 하나 더 생긴다(ECONOMY.md).

## 7. 클럽 안 계속 검사
- 입장한 뒤에도 서버가 클럽 안 사람의 착용 아이템을 계속 확인한다(옷이 바뀔 때마다 + 주기적으로).
- 드레스코드가 안 맞게 되면(아이템을 벗음) **경고창: "드레스 코드가 맞지 않습니다." + 30초 카운트다운.**
- 30초 안에 맞는 아이템을 입으면 **그 즉시** 경고가 사라진다. 입었는데 내보내는 일이 없도록, 내보내기 직전에 서버가 한 번 더 확인한다.
- 30초가 지나도 안 맞으면 클럽 밖(입구 바깥)으로 내보낸다.

## 8. 예외
- **VIP, DJ**: 검사 없이 통과(안에서도 경고 없음).
- **클럽 알바**(나중에 구현하면): 손님 입구가 아닌 **알바생 전용 통로**로 출입.
- 이벤트가 아닐 때: 누구나 입장(기존 클럽 규칙 그대로).

## 9. 보상
- 드레스코드를 맞춘 것에 대한 따로 보상은 없다. **입장만 허용.**

## 10. 가드 캐릭터 (게임 완성 후 이벤트 만들 때 제작)
- 사용자가 직접 만든다. 방법:
  - A(추천): 로블록스 계정(부계정 가능)에 가드 옷을 입히고 사용자 이름을 알려 주면, 착장을 읽어 가드 모델로 만들고 아이템 번호를 코드에 저장한다(나중에 그 계정 아바타를 바꿔도 가드는 그대로).
  - B: 카탈로그 아이템 번호 목록 + 피부색·체형을 알려 준다.
  - NPC라 아이템을 실제로 사지 않아도 입힐 수 있다.
- Creator Store 후보(2026-10-22 확인: 예전 스타일 블록 아바타)는 쓰지 않는다.

## 11. 구현 메모 (그때 할 일)
- `ClubDressConfig.lua`: 시즌 목록, 색별 단어 목록, 문구, 튕김 거리 3, 경고 30초, 뽑기 1코인.
- `ClubDressService`(서버): 기간 판정(KST), 아이템 판정 + 캐시, 가드 검사 대기열, 튕기기, 클럽 안 감시·경고·내보내기, 뽑기(카탈로그 검색 + 입어 보기).
- 클라이언트: 간판 공지, 가드 말풍선, 결과 문구, 경고창 카운트다운, 뽑기 버튼.
- ClubAccessService(VIP/DJ 출입)와 같은 방식으로 Workspace 안의 태그만 사용.
- 팝업 규칙(D-098: 팝업 하나만), 상단 버튼 아래 위치(TopBar.bottom())를 따른다.
- 테스트: 모바일 2인(통과/실패/튕김, 안에서 벗기 → 30초 안에 다시 입기 → 경고 해제, 30초 경과 → 퇴장, VIP·DJ 예외, 뽑기·다시 뽑기).
