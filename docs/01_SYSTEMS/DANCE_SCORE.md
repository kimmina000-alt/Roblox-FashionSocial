# 안무 따라 하기 점수 — "오늘의 곡 도전" (기획, D-1814)

상태: 기획 + 화면 시안만. 코드는 아직 없음 (사용자 2026-11-21 "응 시작", 진행 관리 세션 경유).
시안 캔버스: https://claude.ai/artifact/3KTo2VS6jySsX6Z7VzBKpU (스타일 A 네온 클럽 / B 노을 팝 / C 음악방송, 각 5장: 도전 시작 · 플레이 가로 · 플레이 세로 · 결과 · TOP 10 전광판). 사용자가 스타일을 고르면 그 줄로 만든다.

## 1. 왜

- 대시보드 11-21: 1일 유지율 약 2 % (비교 기준 약 10 %). 다시 올 이유가 없다.
- 장소별 머문 분: 목적지 중 클럽 1위(밤에만 여는데도), 오후네컷 2위. K-POP 춤 + 사진이 핵심.
- 매일 바뀌는 곡 + 하루 순위 = 내일 다시 올 이유. 이미 있는 안무(ClubChoreo)를 게임으로 쓴다.

## 2. 무대 (사용자 결정 11-21: "오늘의 곡 대결은 네온 무대에서 할 것")

- 포켓 공원 광장 네온 무대(NeonStageService, tools/graybox/park_neon_stage_1118.lua). 낮 · 밤 모두 열림. 클럽에서는 하지 않는다.
- 네온 무대 위에 서면 화면에 "🎵 오늘의 곡 도전" 버튼. 무대 밖에서는 안 보인다.
- 무대 위 자리 6칸(바닥 표시). 여러 명이 동시에 각자 도전할 수 있다.
- TOP 10 전광판: 네온 무대 뒤 벽, 무대를 보는 쪽(계단 옆 순위판(D-1821) 근처). 클럽 안에는 두지 않는다.

## 3. 곡 나누기 (네온 무대는 지금 무작위 안무 곡, D-1820 / D-1884)

- 무대 스피커는 지금처럼 무작위 안무 곡(3~4곡마다 NEON)을 튼다. 구경꾼은 바뀌는 게 없다.
- 도전하는 사람의 귀에만 오늘의 곡이 처음부터 나온다(그 클라이언트의 자기 곡 시계). 무대 곡은 그 사람에게만 끈다.
- 다른 사람 화면: 도전자는 오늘의 곡 안무를 크게 추고(RemoteChoreoSync처럼 도전자의 곡 시계 기준), 머리 위에 작은 "🎵 도전 중 · 콤보 N".
- 도전이 끝나면 다시 무대 곡이 들린다.

## 4. 한 판

1. 도전 시작 화면: 오늘의 곡 · 남은 시간(05:00 KST까지) · 내 최고 · 오늘 순위 · 참여 보상 · [도전 시작].
2. 3 · 2 · 1 → 곡 약 3분. 화면 아래 버튼 4개(폰 엄지 크기 64~92 px). 표시가 내려오거나(A, C) 한 줄로 흘러온다(B).
3. 판정: Perfect / Great = 아바타가 그 곡 안무를 크게, 콤보 +1. Miss = 아바타가 한 박자 멈칫, 콤보 0.
4. 결과 화면: 등급 S / A / B, 점수, Perfect · Great · Miss 수, 최대 콤보, 오늘 순위, [다시 도전] [순위 보기] [닫기].

카메라: 도전자만, 무대 앞 정면에서 아바타 전신 + 위쪽 여유(판정 글자 자리). 🎥 무대 카메라 샷은 도전 중에는 끈다. 끝나면 원래 카메라.

## 5. 표시(노트) 뽑기

- ClubChoreo 조각의 `at`(원곡 초, D-876) + 곡 박자(tools/choreo/review 박자 도구)에서 자동으로 만든다. 박자 위에만 둔다.
- 버튼 1~4는 그 박자의 큰 동작 방향(팔 왼쪽 / 아래 / 위 / 오른쪽)에서 고르고, 같은 버튼 연타는 줄인다.
- 곡마다 표시 수를 미리 만들어 Shared/DanceScoreCharts 같은 모듈에 둔다(게임 중 계산 없음).

## 6. 판정과 지연

- 판정은 클라이언트가 자기 곡 시계로 한다(폰 지연 보정: 처음 한 번 "박자에 맞춰 누르기"로 잰 값).
- 서버는 끝난 점수만 받고, 말이 안 되는 점수(표시 수보다 많은 Perfect, 너무 짧은 판, 시작 전 점수)만 거른다.
- Perfect ±60 ms, Great ±120 ms (처음 값, 테스트로 조정).

## 7. 순위와 보상

- 오늘의 곡: 안무 있는 곡 중 하나, 매일 05:00 KST에 바뀜(출석 이벤트와 같은 날 기준, D-1693). 권리 걱정이 적은 곡부터.
- 하루 순위: OrderedDataStore, 키 = 날짜 + 곡. 각자 최고 점수만. Studio에서는 쓰지 않는다(라이브 DataStore 금지 규칙).
- 보상: 1~3위 하루짜리 칭호(다음 날 05:00까지), 참여 코인 조금(+[N], 하루 1번). 주간 1위 오후네컷 프레임 · 팀 점수는 나중에.

## 8. 할 일 (코드는 메인 세션의 첫 방문 카드 · 스폰 다음)

1. 사용자: 스타일 A / B / C 고르기.
2. 표시 뽑기 도구 + 곡 1개로 시험.
3. 네온 무대 버튼 · 플레이 화면 · 판정 · 결과.
4. 하루 순위 + 전광판 + 칭호 / 코인.
5. 모바일 2P 테스트(도전자 1 + 구경꾼 1: 구경꾼이 무대 곡을 계속 듣고 도전자의 안무를 보는지).
