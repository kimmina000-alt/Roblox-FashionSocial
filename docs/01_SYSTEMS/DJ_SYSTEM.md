# DJ 시스템 — 기획서

기준일: 2026-10-20
상태: **1차 구현(DJ 시간 구매·DJ 존 출입·곡 선택) / 확장 기능은 자리만 마련.** 상품 ID 미등록(Studio 테스트 구매로 검증).
코드: `Services/DjService.lua`(DJ 자리·시간·대기열), `Services/ClubService.lua`(음악·신청곡·DJ 조작), `Services/ClubAccessService.lua`(DJ 존 출입), `ClubMusicController.client.lua`(🎵 패널·DJ 콘솔), `Shared/MonetizationConfig.lua`(상품 ID·가격)

---

## 1. 무엇인가
클럽 동쪽 DJ 존(형광 하늘색 LED 월이 있는 무대)은 **DJ 시간을 산 사람만** 올라갈 수 있다. DJ는 서버 전체의 클럽 음악을 고른다. DJ가 없을 때는 누구나 한 곡씩 신청할 수 있다.

## 2. 현재 동작 (Studio 확인 2026-10-20)
| 상황 | 동작 |
|---|---|
| DJ 없음 | 자동 재생목록. 누구나 🎵 패널에서 **신청**(한 사람 한 곡, 최대 10곡 대기). 신청곡이 먼저 나온다 |
| DJ 존에 들어가려 함 | 투명 벽에 막히고 **Roblox 결제창**(DJ 30분). 점프 등으로 들어가도 0.5초 안에 밖으로 이동 |
| DJ 시간 구매 | 자리가 비어 있으면 즉시 30분 DJ. 현재 DJ가 또 사면 30분 연장. 다른 사람이 DJ 중이면 **대기열**에 들어가고 차례가 오면 시작(시간 손실 없음) |
| DJ | DJ 존 출입, 🎵 패널: **지금 틀기 / 다음 곡 / 건너뛰기**, 남은 시간 표시. DJ가 시작하면 열린 신청곡은 정리된다 |
| DJ가 나감 / 시간 끝 | 다음 대기자에게 넘어감. DJ 존 안에 있으면 밖으로 이동 |
| DJ 중 다른 사람 | 신청 불가("지금은 DJ가 곡을 고르고 있어요"), DJ 이름·남은 시간·대기 인원 표시 |

곡은 **게임이 제공하는 재생목록(라이선스 확인된 음원)만** 고를 수 있다. 플레이어가 음원을 올리거나 방송하는 기능은 없다(CLUB.md §6).

## 3. 가격·시간 제안 (D-052, 결정 필요)

### 3.1 시간 단위: **30분** 권장
- 우리 재생목록 평균 곡 길이 ≈ 3분(11곡 평균 177초).
  - 10분 = 약 3곡 → DJ "세트"라기보다 신청 몇 번에 가깝다. 구매 → 부스 이동(클럽 입구에서 약 15초) → 곡 고르기까지 고려하면 실제 플레이는 더 짧다.
  - 30분 = 약 10곡 → 하나의 세트. 소셜 게임의 한 번 접속 시간과 비슷한 길이라 "이번 접속 동안 내가 DJ"라는 경험이 된다.
  - 60분 = 서버당 DJ 자리가 하나뿐이라 한 사람이 너무 오래 독점한다(다른 사람의 구매 기회가 줄어든다).
- 연장은 같은 상품을 한 번 더 사는 방식(30분 추가).

### 3.2 가격: **30분 75 R$** 권장 (테스트 범위 49~99 R$)
근거:
1. **소모성 상품의 충동 구매 구간**: 소모성(시간제) 상품은 보통 수십 R$ 대에서 가장 잘 팔린다. 75 R$는 약 1달러 이하 체감 구간이다(로벅스 구매 가격 기준, 지역·묶음에 따라 다름).
2. **영구 상품과의 관계**: VIP 패스(영구, 299 R$ 가정)보다 확실히 싸야 "한 번 해 볼까"가 된다. 30분 4번 = 300 R$로, 자주 하는 사람에게는 VIP 패스 급 지출이 된다.
3. **희소성**: 서버에 DJ 자리가 하나라 시간당 최대 판매량이 정해져 있다(서버당 시간당 최대 150 R$). 너무 싸면(예: 10 R$) 한 사람이 계속 연장해 독점하고, 너무 비싸면(예: 300 R$) 아무도 사지 않아 DJ 존이 늘 비어 볼거리가 없다.
4. **영향력**: DJ는 서버 전원(24~30명)이 듣는 음악을 바꾼다. 개인 아이템(환타 6 R$)보다 영향력이 훨씬 크므로 그보다 한 자리 높은 가격대가 맞다.
5. **참고 게임**: MASS에서 머니건 350 R$(영구), 가드 역할 990 R$(영구). DJ는 시간제라 이보다 낮게 둔다.

출시 후 판매율을 보고 49 / 75 / 99 R$ 중 하나로 조정한다(구매 전환율 × 가격이 가장 큰 값).

### 3.3 운영 규칙(제안)
- 나가면 남은 시간은 사라진다(구매 창과 패널에 안내 필요 — **현재 미표시, 다음 작업**).
- DJ 대기 중 나가면 대기 취소(구매한 시간도 사라짐) → 이 부분은 환불 이슈가 될 수 있으므로 "대기 중일 때는 구매 버튼에 경고"를 넣거나 **대기열이 있으면 구매를 막는 방안**도 검토.

## 4. 앞으로 붙일 DJ 기능 (코드 자리 마련됨)
DJ 기능은 `DjService.Actions[이름] = function(player, payload) ... end`로 등록한다. 🎵 패널의 Music remote에서 음악 이외의 동작은 이 표로 넘어가며, DJ만 실행할 수 있다(서버 확인).

| 후보 | 내용 | 비고 |
|---|---|---|
| 조명 프리셋 | 클럽 조명 색·패턴(파티/칠/스트로브) | 패널에 "조명 (준비 중)" 버튼 있음. ClubBeat 태그 파트 사용 |
| 효과 | 꽃가루·불꽃·응원봉 파도(MASS 머니건 대체) | "효과 (준비 중)" 버튼 있음. 쿨다운 필요 |
| 안내 방송 | DJ 한 줄 공지(필터 적용) | TextService 필터 필수 |
| 군중 투표 | 다음 곡 2개 중 투표 | |
| DJ 칭호 | 이름 위 "DJ" 배지, 누적 DJ 시간 기록 | |
| 템포·BPM 연동 | 춤 템포와 곡 BPM 맞추기 | 곡 BPM 데이터 필요 |
