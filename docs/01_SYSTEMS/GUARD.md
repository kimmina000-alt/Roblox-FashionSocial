# 클럽 가드 이용권 (D-623, 2026-10-30)

## 목적
클럽에서 춤·DJ·대화를 방해하는 사람을 플레이어가 직접 정리할 수 있게 한다.
동시에 돈 주고 산 기능이 **괴롭힘 도구가 되지 않도록** 쓰임새와 횟수를 좁힌다.

## 상품
| 항목 | 값 |
|---|---|
| 종류 | 게임 패스 (영구) |
| 키 | `Guard` (MonetizationConfig.GamePasses) |
| 이름 | 가드 패스 (VIP 패스와 같은 이름 꼴, 처음 기획 이름은 "클럽 가드 이용권") |
| 가격 | **399 R$** (2026-10-31, 199에서 올림: VIP 299보다 위, 다른 클럽 게임 399~1450 참고, 가드 수를 줄여 남용도 줄임) |
| 판매 위치 | 클럽 아이템 상점 아래 패스 줄 (DJ 이용권, VIP 패스 다음) |
| 상태 | live, id 2062319135 (2026-10-30) |

## 가드가 받는 것
1. **머리 위 GUARD 표시**: 검은 판, 굵은 흰 글씨 "GUARD", 빨간 테두리. VIP / DJ 표시보다 위, 조금 크게. 보디가드 느낌.
2. **클럽 밖으로 안내**: 클럽 안에서 다른 사람을 누르면 나오는 카드에 `🛡 클럽 밖으로 안내` 버튼.
   - 대상은 클럽 문 앞 인도로 옮겨지고, **60초 동안 다시 들어올 수 없다** ("1분 격리").
   - 대상에게: "🛡 가드 ○○님이 클럽 밖으로 안내했어요. 60초 뒤에 다시 들어갈 수 있어요."
   - 가드에게: "○○님을 클럽 밖으로 안내했어요."

3. **언제든 클럽 입장** (2026-10-31): 클럽이 닫힌 낮(06:00~18:00)에도 들어갈 수 있다 (ClubAccessService).

## 남용 막기
| 규칙 | 값 |
|---|---|
| 쓸 수 있는 곳 | 클럽 안에서만, 가드와 대상 모두 클럽 안 |
| 대상에서 빠지는 사람 | DJ, 다른 가드 |
| 가드 한 명의 재사용 대기 | 30초 |
| 같은 사람을 다시 안내하기 | 누구든 5분에 한 번 |
| 기록 | 서버 출력에 `[Guard] 가드 → 대상` (신고가 오면 확인용) |
| 하지 않는 것 | 수갑·감옥·움직임 막기·게임 밖 추방(킥). 대상은 클럽 밖에서는 자유롭게 논다 |

수갑으로 붙잡아 끌고 가는 연출은 넣지 않았다. 다른 플레이어의 캐릭터를 강제로 묶는 기능은
로블록스 커뮤니티 기준(괴롭힘)과 신고 위험이 커서, "문 밖으로 안내 + 1분 재입장 금지"로 대신한다.
