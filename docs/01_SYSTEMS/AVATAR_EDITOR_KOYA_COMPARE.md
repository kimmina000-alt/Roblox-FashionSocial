  - **액세서리 조정**: 위에 입은 액세서리 동그라미 줄(고르면 이름 표시, 예 Lollipop_1_V2). **이동 / 회전 / 스케일** 탭. 축마다 `−` 값 `+` **재설정** 버튼과 슬라이더, 숫자 직접 입력. 끌면 **월드의 실제 캐릭터가 바로** 움직임(따로 미리보기 창 없음). 아래 **적용 / 버리기**, "저장되지 않은 변경 사항 · 이 조정을 유지하려면 적용하세요" 안내. **고급 도구**: 거울 · 복사 · 붙여넣기 · Reset all · 부러져 나감(떼어내기로 보임). **조정 프리셋**: 이름을 붙여 Save item(이 아이템) / Save type(같은 종류 전부), 유료면 45개.

## 3. 우리한테 없는 것 · 보완하면 좋은 것 (추천 순)

1. **축마다 `−` / `+` 미세 조정과 숫자 입력** — 슬라이더로는 0.01 단위 맞추기가 어려움. 폰에서 특히 필요.
2. **이동 / 회전 / 스케일 탭** — 지금은 7줄이 한 화면에 다 있어서 폰에서 김. 탭으로 나누면 줄이 3개로 줄어듦.
3. **거울 · 복사 · 붙여넣기 · 전체 초기화** — 양쪽 귀걸이, 양쪽 어깨 장식처럼 좌우 짝인 장신구를 거울로 한 번에 맞춤. 복사/붙여넣기는 같은 모자를 바꿔 쓸 때 편함.
4. **조정 프리셋 저장** — 이름 붙여 저장, "이 아이템만 / 같은 종류 전부". 유료 상품(슬롯 늘리기)으로도 쓸 수 있음.
5. **장신구 고르는 줄을 동그라미 아이콘 + 이름 표시로** — 우리는 카드 5개라 많이 입으면 두 줄. 가로 스크롤 한 줄 + 선택한 이름이 위에 크게.
6. **신체 크기 한 막대** — 키 · 너비 · 머리를 비율 그대로 한 번에 키우고 줄이기.
7. **의상 레이어 순서 끌기** — 레이어드 옷(재킷 위 셔츠 등) 순서. 지금은 메이크업 순서만 있음.
8. **커스텀 ID 입력으로 바로 입기 + 최근 기록 🕘** — 친구가 알려준 아이템 번호로 바로 입어 보기.
9. **장착됨 화면을 종류별 칸(액세서리 / 의상 / 애니메이션 / 몸) + 카드마다 제거** — 우리 "착용 중"은 한 줄 띠.
10. **의상 폴더 · 코드 사용(코디 공유 코드) · 커뮤니티 의상** — 옷장에 폴더, 코디를 코드로 친구에게 보내기. 소셜 게임이라 효과 클 것.
11. **캐릭터 재설정**을 편집기 맨 위에 — 우리는 카탈로그 초기화 버튼(D-1032)이 있으니 편집기에서도 같은 버튼을 보이게.
12. 커스텀 얼굴(머리 모양별 얼굴)은 KOYA도 유료 잠금이고 Roblox 규칙상 범위가 좁아 뒤로.
