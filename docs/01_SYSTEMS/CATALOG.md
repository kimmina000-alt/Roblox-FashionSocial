# Catalog System

## Global Rule
Catalog는 Central Plaza, Cafe, Park, Beach, City, Night Area, Housing, Club, Photo Spots, Runway 등 어디서든 접근 가능하다.

## Functions
Search / Browse / Detail / Temporary Try-on / Equip / Unequip / Current Outfit / Player outfit inspection / Same-item try-on / Roblox purchase.

## Social
플레이어를 클릭해 현재 착용 아이템을 보고 같은 아이템을 시도할 수 있게 한다.

## Ownership
Try-on은 구매가 아니다. 실제 구매는 Roblox purchase flow.
