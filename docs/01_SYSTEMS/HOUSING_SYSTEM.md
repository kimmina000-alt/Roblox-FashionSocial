# Housing System

Status: **Deferred — furthest priority; not part of the current MVP.**

Housing was considered as a possible extension for players who enjoy customization, but the current game's identity is catalog-based avatar styling and social play. Housing is not required to validate that core experience.

Deferred scope:
- Personal plots and home exterior customization
- House color/pattern customization
- Structural building: walls, floors, doors, windows, stairs, roofs and room layout
- Furniture placement, move, rotate, delete and furniture assets
- House/furniture persistence
- Friend visits, permissions and sharing

Do not implement Housing or add Housing data to the MVP schema before Catalog, Saved Outfits, Club and Photo Spots have been evaluated through playtesting.

If reconsidered, separate cosmetic house customization (color/pattern) from structural editing and furniture placement; these have different implementation costs. Revisit the entire feature only if it clearly strengthens the game's identity.
