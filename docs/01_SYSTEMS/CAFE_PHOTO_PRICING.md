# 카페·포토부스 가격 제안 (2026-10-26, D-310 제안 — 사용자 확인 전)

원칙(사용자): 모든 기능은 코인으로 쓸 수 있고, 추가 옵션만 Robux.

## 1. 코인 수입 (지금 코드 기준)
| 수입 | 양 | 설정 |
|---|---|---|
| 접속 | 1분에 💰1 | EconomyConfig.PassiveAmount |
| 카페 알바 | 서빙 💰4, 치우기 💰2, 하루 최대 💰60 | CafeJobConfig |
| 보너스(첫 접속 등) | 꺼져 있음 | EconomyConfig.BonusesEnabled = false |
| 코인 x2 패스·부스트 | 위 전부 2배 | D-278 |

하루 수입 예:
- 30분 놀다 가는 사람: 💰30
- 1시간 + 알바: 💰120
- x2 패스 보유자: 💰240

기준: 1 R$ = 💰10 (D-269).

## 2. 지금 있는 코인 사용처
| 무엇 | 가격 |
|---|---|
| 클럽 음료 1단계 | 무료 / 💰1 / 💰5 |
| 클럽 음료 2단계 (6잔 병, 나눠 마심) | 💰100 / 💰150 |
| 아이스크림 | 💰15 |
| 인생네컷 추가 저장 | 💰20 / 장 (→ 아래 제안 💰10) |
| 프레임 (영구 해금) | 그레이 💰120, 파스텔 💰200 (→ 아래 제안) |

## 3. 포토부스 제안
- **저장 장수:** 같이 찍은 사람마다 1장씩 무료예요. 둘이 찍으면 각자 1장, 합쳐서 2장이 돼요. 2장째부터 💰20 → **💰10**으로 내리고, 최대 5장은 그대로 둬요.
  - 추가 저장은 내 사진첩에 같은 사진이 한 장 더 생길 뿐이라 쓸모가 적어요. 그래서 가격을 낮춰요.
  - 나중에 "친구에게 선물"이나 "포토월에 붙여도 사진첩에 남음"처럼 쓸 곳을 붙이면 💰20으로 되돌려도 돼요.
- **프레임은 해금 방식(한 번 사면 영구):** 찍을 때마다 돈을 받으면 매번 아까워서 안 쓰게 돼요. 해금 방식은 모으는 재미와 목표가 생겨요.
  | 단계 | 프레임 | 지금 | 제안 |
  |---|---|---|---|
  | 1 무료 | 블랙, 화이트 | 무료 | 무료 |
  | 2 | 그레이 | 💰120 | **💰50** (1시간 놀면 첫날 해금) |
  | 3 | 파스텔 5색 (핑크·하늘·민트·레몬·라일락) | 각 💰200 | **각 💰100** (꾸준히 하면 하루 1색, 5색 💰500) |
  | Robux | 글로시 네온·글로시 핑크·반짝이 골드·반짝이 실버 | 프레임 팩 99 R$ | **그대로 99 R$, 4종 전부 영구** |
  - 프레임 팩 99 R$는 특별 프레임 4종 전부를 한 번에 영구로 쓰는 가격이에요. 나중에 특별 프레임이 늘어나면 팩 2를 따로 만들어요(PRODUCTS.md §5).

## 4. 카페 메뉴 제안 (1인분, 코인)
실제 가격 참고: 스타벅스 톨 아메리카노 4,700원(2025-01 인상), 라떼 약 5,200원, 카라멜 마키아또 약 6,100원. 동네 카페는 소금빵 2,500~3,700원, 크림치즈 베이글 4,200원~. 그 밖에 티·스무디·프라푸치노·에이드 약 5,700~6,500원, 크루아상류 4,000~7,000원, 허니브레드 약 8,000~10,000원, 조각 케이크 약 6,500~8,000원, 파르페 약 9,000~12,000원.

| 단계 | 음료 | 디저트 | 가격 |
|---|---|---|---|
| 1 무료 | 물, 아메리카노 | — | 무료 |
| 2 | 카페라테, 카푸치노, 카라멜 마끼아또 | 소금빵, 베이글 | **💰10** |
| 3 | 티, 스무디, 프라푸치노, 에이드 | 딸기 크림 크루아상, 허니카라멜브레드 | **💰20** |
| Robux | 파르페 | 홀케이크 (딸기생크림, 티라미수, 바스크치즈케이크) | 아래 |

- 단계 나누기는 사용자 안을 그대로 쓰고, 실제 가격대와도 맞아요. 허니브레드는 실제로 가장 비싸서 3단계 맨 위에 둬요.
- 💰10 / 💰20으로 정한 이유:
  - 30분 플레이어(💰30)도 한 번 오면 2단계 하나와 3단계 하나를 사 먹을 수 있어요.
  - 아이스크림(💰15)과 가격대가 맞아요.
  - 클럽 2단계 병(💰100, 6명이 나눠 마심)보다 1인분이라 싸요.
- **Robux는 "나눠 먹는" 상품이 가치가 있어요(클럽 병과 같은 방식).**
  - 파르페 1잔(혼자, 큰 잔에 화려한 모양): **15 R$**
  - 홀케이크: 테이블에 놓으면 6조각을 모두가 가져가요. 3종 각 **25 R$**
- Robux 상품이 4개 늘어요(Creator Dashboard 등록 34 → 38개). SKU: CAFE-DP-PARFAIT, CAFE-DP-CAKE-STRAWBERRY / -TIRAMISU / -BASQUE.
- 카페 음료와 디저트는 알바 주문 목록에도 그대로 들어가요(직원이 만드는 메뉴).

## 5. 결정
- **포토부스 결정 (D-311, 2026-10-26):** 추가 저장 💰10, 그레이 💰50, 파스텔 각 💰100, 프레임 팩 99 R$. PhotoConfig에 반영했어요.
  - 프레임은 사진 찍기를 시작한 주 플레이어(호스트)가 가진 것만 확인해요. 고른 프레임은 같이 찍은 친구 사진에도 똑같이 적용돼요(PhotoBoothService confirm, 기존 동작).
- 카페: 위 §4 그대로 진행(사용자 "그렇게 진행하자"). 코드는 편의점·국밥집과 함께 만들어요.

## 6. 편의점 OH24 (제안, 코인만)
실제 편의점 가격: 생수 약 1,000원, 삼각김밥 1,300~1,800원, 컵라면 1,200~1,800원, 바나나우유 약 1,700원, 과자 1,500~2,000원, 아이스크림 바 1,000~2,500원.
카페 2단계(약 5,000원) = 💰10이므로, 대략 **💰1 ≈ 500원**으로 맞춰요.

| 상품 | 가격 |
|---|---|
| 생수 | 💰1 |
| 아이스크림 바 / 콘 | 💰3 |
| 과자 (감자칩, 초코과자) | 💰3 |
| 바나나우유 / 탄산음료 캔 | 💰3 |
| 삼각김밥 | 💰3 |
| 컵라면 (창가 테이블에서 먹기) | 💰4 |

- 혼자 금방 사서 손에 들고 다니는 싼 간식이에요. 해변 아이스크림 트럭(💰15, 소프트콘)보다 싸요.
- 술과 담배는 팔지 않아요(콘텐츠 규칙).

## 7. 국밥집 (제안, 클럽 근처)
노리는 동선: 클럽에서 밤새 놀고 나와서 국밥 먹으러 가는 롤플레잉. 실제 가격은 국밥 1그릇 약 9,000~11,000원이에요.

| 메뉴 | 가격 |
|---|---|
| 돼지국밥 / 순대국밥 / 소고기국밥 | 💰20 |
| 공깃밥 추가, 김치·깍두기 | 무료 (반찬은 테이블에 기본) |
| Robux: 수육 한 접시 (테이블에 놓으면 6점을 모두가 가져감) | 19 R$ |

- 💰20은 카페 3단계와 같아요. 30분 플레이어도 하루에 클럽 1단계 음료와 국밥 한 그릇을 먹을 수 있어요.
- 술은 없어요. "해장" 같은 술 관련 말도 쓰지 않아요.
- 실내는 일반 식당처럼 탁 트인 홀로 만들어요(작은 개인 방 금지 규칙).
- 위치와 외관: 클럽 근처 후보를 사진으로 보여 드리고, 고르시면 지어요.
