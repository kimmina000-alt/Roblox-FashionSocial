# 오후네컷 프레임 목록 (2026-10-30 확정)

코드: `src/ReplicatedStorage/FashionGame/Shared/PhotoConfig.lua` (`PhotoConfig.Frames`), 그림: `PhotoRender.lua`.
사진 아래 글씨는 모두 `OHU`.

## 1. Creator Dashboard에 등록할 것

프레임은 **게임 패스 1개**로 판다. 프레임마다 따로 등록하지 않는다.

| 항목 | 값 |
|-|-|
| 종류 | 게임 패스 (한 번 사면 영구) |
| SKU / 코드 키 | `PHOTO-PASS-FRAMEPACK1` / `FramePack` |
| Roblox ID | 2052036510 (이미 만들어져 있음, live) |
| 이름 (수정) | 프레임 팩 (특별한 프레임 12종) |
| 설명 (수정) | 오후네컷 특별한 프레임 12종(네온·글로시·반짝이·캐릭터)을 영구로 써요. |
| 가격 | R$ 99 (지금 값. 12종으로 늘었으니 149도 검토) |
| 아이콘 | 블랙 네온 + 몽이 프레임 사진 추천 (512×512) |

대시보드에서 바꿀 것: 이름, 설명, (원하면) 가격, 아이콘. ID는 그대로라 코드는 안 바꿔도 된다.
가격을 바꾸면 `MonetizationConfig.GamePasses.FramePack.price`도 같은 값으로 맞춘다.
