# 한옥 마을 (Hanok Village) — 회색 박스 (2026-10-22)

사용자 레퍼런스(한옥 마을 사진 모음)를 하나씩 보고 만든 요소:

| 레퍼런스 | 마을에 넣은 것 |
|---|---|
| 기와지붕 + 붉은 벽돌 + 화강암 담장 | 마을 둘레 **꽃담** (화강암 아래, 붉은 벽돌 띠, 기와 지붕돌) |
| 흰 벽 + 노란 꽃나무 + 나무 벤치 | 서쪽 입구 쪽 **흰 담장 + 노란 꽃나무 2그루 + 벤치(앉기) + 화분** 포토 스팟 |
| 감나무 + 한옥 툇마루 의자 | **OHU 한옥카페 마당의 감나무** + 나무 테이블과 의자 |
| 연못 + 정자 / 연꽃 + 다리 | 가운데 **연꽃 연못**, 물 위 **정자**(사각 지붕, 앉기 4곳, 북쪽 나무 데크로 연결), **아치형 나무다리**(남쪽 정원으로 건넘) |
| 안마당 정원, 디딤돌, 석등 | 한옥카페 마당의 **디딤돌, 석등, 돌** |
| 현대식 한옥 + 통유리 | **OHU 한옥카페** = 퓨전 한옥: 유리 미닫이 앞면, 마루 바닥, 좌식 테이블 3 + 방석(앉기), 안쪽 작은 정원, 주문 카운터 |
| 창살 너머 풍경 | 남쪽 정원 **창틀 포토 스팟** — 나무 창살 너머 벚나무 |
| 북촌 골목 (돌길, 석양, 계단) | **돌 포장 중앙 골목** + 등롱, 서쪽 **돌계단 골목**(높이 8 언덕으로) |
| 언덕 위 한옥들 | 서쪽 **언덕 테라스**에 한옥 2채 + **전망 정자**(지붕 너머 마을 전망) + 소나무 |
| 벚꽃 대문 | 북쪽 **솟을대문**(열린 문짝, 기와지붕) 양옆 벚나무 4그루 |

한옥 집(5채): 돌 기단, 나무 기둥, 흰 벽, 앞면 **창호(격자 창살)**, **툇마루(앉기 3곳)**, 맞배 기와지붕(처마 끝 올림, 용마루, 박공). 장식용(진입불가) — 문을 창호로 닫아 둠 (거리 건물 원칙).

## 플레이어 동선
1. 루프 → **북쪽 대문**(벚꽃, 포토 스팟) → **중앙 골목**(양옆 한옥, 등롱)
2. 골목 끝 → **연못**: 왼쪽 데크로 **정자**(앉아서 쉬기), 오른쪽 **아치 다리**로 연못을 건너
3. **남쪽 정원**: 벚나무, 벤치, **창살 너머 벚꽃** 포토 스팟
4. 동쪽 **OHU 한옥카페**: 감나무 마당 → 주문(E) → 좌식 테이블에 앉아 마시기
5. 서쪽 **돌계단 골목** → 언덕 테라스 → **전망 정자**에서 지붕들 내려다보기
6. 입구 근처 **노란 꽃나무 담장** 포토 스팟
