# 소품샵 (Prop Shop) — 계획만

기준일: 2026-10-22 · 상태: **계획만 / 구현하지 않을 수도 있음** (사용자)
관련: `docs/01_SYSTEMS/HOUSING_SYSTEM.md`, `docs/02_WORLDS/CITY_STREET.md`

## 1. 목적
나중에 **집 인테리어 아이템**을 파는 상점. 실제 판매 기능은 **주택 시스템과 함께** 연다.

## 2. 디자인
- **홍대 소품샵 느낌:** 작은 쇼윈도, 가랜드·조명 줄, 진열 선반 가득한 아기자기한 외관, 손글씨 간판.
- 간판 상호는 게임명 규칙을 따른다 (OHU, `docs/00_PROJECT/VISION.md` §게임명) — 예: "OHU HOME".

## 3. 지금 할 것
- 외관만 만든다. 둘 중 하나:
  - **"OPEN 준비 중" 현수막**을 단 닫힌 상점 (문은 닫아 두고, 들어갈 수 있다는 기대를 만들지 않음), 또는
  - 그냥 **거리 건물**로 둔다 (CITY_STREET.md §7 원칙).
- 판매 UI, 아이템 데이터, 결제는 만들지 않는다.

## 4. 열 때 정할 것
- 주택 시스템 범위, 아이템 목록, 코인/Robux 가격 (ECONOMY.md, MONETIZATION.md).
