# OHU 배치도 v1 — 홍대입구역 주변을 본뜬 구조 (안, 2026-10-22)

그림: `docs/04_ART/diagrams/ohu_hongdae_layout_v1.svg` · 상태: **Studio에 임시 적용(되돌리기 가능), 사용자 확인 대기** — 아래 "Studio 임시 적용"

## 왜 바꾸나 (사용자)
"한국에 현실적으로 저런 공간 없음. 홍대 핫플레이스를 기준으로 복사 붙여넣기 한 것처럼 배치." + 지하철역에서 시작해 출구 번호로 구역을 나눔(1번 클럽, 2번 한옥 마을, 3번 해변).

## 실제 홍대 구조 (조사)
| 실제 | 특징 | 게임에서 |
|---|---|---|
| 홍대입구역 (2호선·공항철도·경의중앙선) | 양화로 큰길 아래, 출구 여러 개 | **OHU입구역** 지하 대합실 = 스폰·🏠 |
| 9·8번 출구 → 어울마당로 | 걷고 싶은 거리, 버스킹, 레드로드 (8번 출구 근처) | **걷고싶은거리·레드로드** (빨간 포장 길) |
| 레드로드 R9 잔다리로~와우산로~상수역 | 일명 "클럽거리" | **① 클럽거리 → OHU CLUB** |
| 홍대 놀이터(홍익어린이공원) | 주말 프리마켓·공연 | **홍대 놀이터 광장** (지금 중앙 광장 역할: 버스킹 무대·벤치) |
| KT&G 상상마당 | 메인 레드로드 옆 문화 건물 | **패션위크 백스테이지** |
| 인생네컷·포토 부스 | 홍대 골목마다 있음 | **인생네컷 거리** (OHU PHOTO) |
| 3번 출구 → 경의선숲길 연남동 구간 | "연트럴파크", 잔디·실개천, 동진시장 골목 카페·책방 | **④ 경의선숲길(연트럴파크) → 연남동 카페거리(Glasshouse 카페, 소품샵) → 끝에 공원 놀이기구** |

| 양화로 대로변 | 노래방·스터디카페·세탁소·노점 | 거리 건물(CITY_STREET.md §7) |

※ 실제 출구 번호는 홍대입구역과 다르게, 사용자 요청대로 ①클럽 ②한옥 ③해변 ④연남·공원으로 정함. 방향(클럽은 남서, 연남은 북서, 한강은 남쪽)은 실제와 같게.

## 플레이 흐름
1. 접속 → 지하 대합실(개찰구, 출구 안내판 ①②③④, 🏠도 여기로).
2. 출구 계단으로 올라가면 그 구역 입구 앞. 걷고싶은거리는 ①과 ③ 사이를 이어 주는 "메인 거리"(인생네컷·놀이터 광장·패션위크).
3. 구역끼리도 걸어서 연결 (지하철 타고 다시 나올 필요 없이).

## v4 — 사용자 손그림 (기록)
손그림: `docs/04_ART/diagrams/ohu_layout_v4_user_sketch.png` → 블록아웃: `ohu_layout_v4_studio.png`. 스크립트 `tools/graybox/hongdae_v1_temp.lua` (v4).
- 축척: 손그림에 클럽·공원 놀이기구가 실제 크기로 붙어 있어 1 stud ≈ 3 px로 읽음. 로터리 중심 = (0,0).
- **방향 기준 = Studio 위에서 본 화면: 화면 위 = -Z(북), 오른쪽 = +X(동).** 처음엔 +Z를 위로 그려 Studio에서 상하가 뒤집혀 보였음(사용자 지적) → 남북을 뒤집어 다시 지음. 해는 +X(동)에서 떠서 -X(서쪽 바다)로 짐(이건 그대로). 그림 파일도 같은 방향.
- 구역 안쪽 배치(한옥 집들, 놀이기구 순서)는 거울처럼 뒤집을 수 없어서 원래 모양 그대로; 대문 동향·클럽 입구 서향·카페 테라스(길 쪽)는 맞춤.
- 회색 = 아스팔트 길, 가운데 초록 원 = 잔디밭(로터리), 빨간 박스 = 가짜 건물(진입불가), 파란 박스 = 편의점.
- 로터리(반지름 78, 잔디 반지름 38) 네 방향 길 + 해변 쪽 남북 길 + 남서 동서 길 + 동쪽 남북 길 + 북동 동서 길.
- 지하철 출구 4개 = 로터리 모서리: 1번 클럽(북동) · 2번 한옥(남동) · 3번 공원(북서) · 4번 해변·카페(남서). 스폰 = 로터리 잔디밭(대합실은 나중에).
- 클럽: 로터리 북동, 입구·네온이 서쪽 북쪽길(클럽거리)을 봄. 런웨이는 클럽 뒤(북쪽). 인생네컷: 클럽 아래, 로터리 동쪽. 한옥: 남동, 대문 동향(손그림보다 작음 — 실제 크기 그대로). Glasshouse 카페: 남서, 길쭉하게(90° 회전). 공원: 북서. 해변·해변 카페: 서쪽 그대로. 예전 원형 광장(01)은 통째로 치움.

## v2 — 햇빛 방향 기준 (기록)
그림: `docs/04_ART/diagrams/ohu_layout_v2_studio.png`. 스크립트는 같은 `tools/graybox/hongdae_v1_temp.lua` (v2 내용).
- **Roblox 실제 방위 (Studio에서 측정):** 해는 +X에서 떠서 -X로 짐, 정오에 -Z 쪽으로 기움 → **동 = +X, 서 = -X, 북 = +Z, 남 = -Z**. 바다는 원래부터 서쪽(-X)이라 석양이 바다 위로 진다.
- 공간별 원칙 (사용자):
  1. **해변 — 서쪽.** 산책로·파라솔·부두·사진 명소가 서쪽 바다를 향하게. 석양 때 주황·분홍 빛 반사. 핵심 = 바다를 보는 시선이 서쪽. → 그대로 + 북쪽 부두 끝에 "석양 포토 스팟" 액자(서쪽 향).
  2. **한옥 마을 — 동쪽/남동쪽.** 대문·주요 건물이 아침 햇빛을 받게. → 남동쪽으로 옮기고 마을 전체를 돌려 **대문이 남동쪽**을 보게 함. 책거리 길이 남동쪽에서 대문으로 들어감.
  3. **해변 카페 — 서쪽 해안 바로 앞.** 창·테라스가 서쪽 바다, 앉아서도 수평선 보이게, 낮고 넓게. → 이미 맞음(서쪽 유리벽, 낮은 창가 바, 서쪽 테라스, 1층). 창 앞 포토스팟 판(높이 8)은 디자인 때 옆으로.
  4. **클럽 — 북쪽/북동쪽 독립 구역.** 실내 조명·네온이 분위기, 창 작게/어둡게, 공연 공간과 연결, 중앙 광장에서 입구·네온 간판이 보이게. → 광장 북쪽으로 옮기고 180° 돌려 입구·간판이 광장을 봄. 동쪽 옆에 패션위크 런웨이(공연 무대)를 붙임. 지하 구멍도 새 자리로(임시 땅 조각), 옥상 엘리베이터 목적지는 패드 기준이라 같이 따라감.
  5. **포토부스 — 중앙 광장과 동쪽 거리 사이.** 실내 조명, 외부 간판·조형물. → 광장 동쪽 "포토부스 거리" 북쪽 면, 간판이 거리 쪽.
  6. **한옥 카페 — 마을 안쪽.** 대문에서 이어지는 산책 동선, 마당에 햇빛, 처마 아래 그늘 좌석, 해 질 녘 등불. → 마을과 함께 이동(마을 안 동쪽). 등불·시간대 조명은 조명 작업 때.
- 그 밖: 역(OHU입구역) = 광장 바로 남쪽 양화로 위, 스폰. 출구 ① 클럽(북) ② 한옥(동남) ③ 해변(서) ④ 포토부스·공원(동). 공원은 포토부스 거리 동쪽 끝. Glasshouse 카페는 원래 자리(북서).
- 남은 것: 석양·아침 조명 연출(시간대), 한옥 카페 등불, 클럽 외벽 창 처리, 지하 대합실, 확정 후 그래이박스 스크립트에 정식 반영.

## Studio 임시 적용 (v1 기록, 2026-10-22)
- 스크립트: `tools/graybox/hongdae_v1_temp.lua` (Studio 명령줄, 편집 모드). 맨 위 `MODE`를 `"apply"`/`"revert"`로.
- 결과 그림: `docs/04_ART/diagrams/ohu_hongdae_v1_studio.png` (Studio 파트로 그린 위에서 본 모습).
- 방향: 북 = +X, 동 = +Z. 클럽(땅 구멍)과 해변(지형 바다)은 그대로 두고 나머지를 그 둘레에 배치 → 바다가 남쪽 한강이 됨.
- apply가 하는 일: 구역 이동(백스테이지·Glasshouse 카페·공원·인생네컷), 원형 광장 길(Loop/Spoke)과 09_Paths를 ServerStorage `Hongdae_v1_HiddenParts`로 치움, `Workspace.Hongdae_v1_Temp`(역·양화로·레드로드·와우산로·책거리·경의선숲길·상가) 추가, 스폰을 역 안으로.
- revert: 구역을 지은 위치(BuiltPivot)로, 숨긴 파트 복구, 임시 모델 삭제, 스폰 원위치. Studio에서 시험 완료.
- 추가 백업: ServerStorage `Graybox_Backup_Before_Hongdae` (적용 전 맵 통째 복사본).
