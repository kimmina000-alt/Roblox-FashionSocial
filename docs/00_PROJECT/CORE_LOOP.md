# Core Loop

카탈로그 검색 → 지원 아이템 임시 착용 → 다른 플레이어에게 외형 표시 → 아이템 해제/교체 → Current Outfit 갱신 → 코디 저장 → 재접속 후 불러오기 → Club·Photo Spots·Playground에서 아바타로 놀기 → 다시 코디 변경.

핵심 UX: 코디 변경 때문에 Social Flow가 끊기면 안 된다. Current Outfit/Wearing은 서버에서 확인한 실제 적용 외형을 공유한다.

Runway는 추후 확장 후보이며 현재 core loop의 필수 단계가 아니다. 별도 의상 제작은 제공하지 않는다.
