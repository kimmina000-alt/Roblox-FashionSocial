# Design Principles

- **Catalog-Based Styling:** Roblox 카탈로그 아이템만 사용; 별도 의상 제작 기능은 제공하지 않는다.
- **Character First:** 꾸민 아바타를 실제 월드에서 보고 보여 주는 것이 핵심이다.
- **Social First:** Catalog를 사용해도 현재 Social Flow와 월드가 끊기지 않는다.
- **Server-Confirmed Appearance:** 실제 적용 외형이 Current Outfit, Wearing, saved snapshot의 기준이다.
- **Photo-Friendly World:** 서로 다른 구도·조명·배경을 가진 사진 공간을 우선한다.
- **Small Meaningful Interactions:** 그네 등 장소와 맞는 행동을 작은 단위로 추가한다.
- **Official Roblox APIs First:** 지원 여부를 공식 API와 Studio에서 검증한다.
- **Temporary Try-on ≠ Ownership:** 게임 내 착용은 Roblox 계정 소유권을 바꾸지 않는다.
- **No Premature Scope Expansion:** Runway는 추후, Housing은 보류.
- **Implementation ≠ Verification:** 코드 존재만으로 기능 완료를 선언하지 않는다.
