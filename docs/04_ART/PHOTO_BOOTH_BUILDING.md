# 오후네컷 건물 (2026-10-23, D-115)

레퍼런스: `references/photobooth_building_yeonnam.webp`. 사용자가 보낸 사진으로, 연남동 노벨길의 인생네컷 모퉁이 건물(좌측·정면·우측)과 상호명·간판 디자인 지시가 들어 있다.

## 상호명과 간판
- 한글 **오후네컷**, 영문 **OHU4cuts**, 로고는 카메라 조리개 아이콘이다.
- 간판 디자인은 인생네컷 간판처럼 만든다. 흰 띠(파사드 밴드) 위에 흰 입체 글자를 달고, 연보라 옆면과 테두리를 준다.
- 정면(모서리)에는 "오후네컷", 좌측(북쪽 도로 면)에는 "OHU4cuts"를 단다.
- 사진 속 2~3층 맥주 간판은 넣지 않는다(음주 요소 금지). 위층에는 간판이 없다.

## 구조 (`tools/graybox/build_hongdae_layout.lua` "오후네컷 building")
| 부분 | 사진 | 게임 |
|---|---|---|
| 단차 | 화강석 기단, 모서리 계단 | 가게 전체를 1.2 올림(MOVES). 화강석 기단·턱, 모서리 2면에 계단 한 단, 위에 투명 경사로 |
| 정면 | 모서리를 깎은 면, 분홍 프레임 유리문 | 깎은 모서리 11. 분홍 기둥·문틀, 양옆 유리, 가운데 자동 미닫이문(AutoDoor) |
| 좌측 | 흰 벽, 분홍 프레임 광고창, "life4cuts" 간판 | 흰 벽 + 분홍 프레임 연보라 포스터(OHU4cuts) + "OHU4cuts" 간판 |
| 우측 | 흰 타일 벽, 세로로 긴 둥근 창 4개, 나무 데크 | CeramicTiles 흰 벽, 캡슐형 창 4개(흰 테두리 + 어두운 유리), 낮은 나무 데크 |
| 2~3층 | 흰 벽돌, 진갈색 창틀, 층 띠 | 흰 벽돌(Brick), 진갈색 창틀 + 창턱, 2·3층 사이 띠 |
| 옥상 | 난간(철제) | 파라펫 + 철제 난간 + 계단실 |

## 지키는 것
- 실내(부스 2개, 포토 월, 태그)는 그대로 쓴다. 높이만 1.2 올라가고 PhotoBoothService는 상대 위치로 동작한다.
- 1층 천장은 바닥에서 14.8 높이에 있고 조명 4개를 단다. 부스 이름표는 천장 아래(y 14.4)로 내리고 "인생네컷"을 "오후네컷"으로 바꾼다. revert하면 원래대로 돌아간다.
- 그레이박스의 벽·투명 지붕·네온 간판·이름표는 숨김 폴더로 옮긴다. revert하면 다시 나온다.
- 확인 결과(Play): 모서리 쪽과 서쪽 인도에서 걸어 들어가기 OK, 부스 2개 프롬프트 OK, 포토 월 OK. 캡처는 `photo_booth_building_v1.jpg`, `photo_booth_building_side_v1.jpg`.

## 남은 것
- 게임 안 다른 글자(아이템 이름 "인생네컷", 앨범 등)를 "오후네컷"으로 바꿀지는 사용자 확인이 필요하다.
