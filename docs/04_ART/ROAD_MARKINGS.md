# 사거리 노면표시 기준 (조사 2026-10-23)

출처: 도로교통법 시행규칙 [별표 6] 노면표시(2019.6.14. 개정본, 국가법령정보센터), 경찰청 「교통노면표시 설치·관리 매뉴얼」 제3·4장, 나무위키(교통노면표시, 중앙선). 치수 상세는 별표 6의 **그림(표준도)**에 있어 글로 확인된 것만 적는다. 게임 축척: 캐릭터 키 ≈ 5스터드 ≈ 1.7m → **1스터드 ≈ 0.34m**.

## 색
- **황색**: 중앙선, 안전지대, 정차·주차금지 (별표 6 일반기준).
- **청색**: 버스전용차로 (출퇴근만 운영하면 단선, 종일이면 복선).
- **백색**: 나머지(차선, 정지선, 횡단보도, 유도선, 화살표).
- **정차금지지대**: 2019년 별표 6과 경찰청 매뉴얼은 백색. 나무위키는 2023.7.4.부터 황색·굵은 빗금으로 바뀌었다고 설명(원문 미확인). 사용자 강남 사진(`street_06`)은 황색 → **황색으로 표시**.

## 항목별 기준
| 표시 | 기준 | 게임 적용(스터드) |
|---|---|---|
| 중앙선(501) | 편도 2차로 이상·분리대 없음 → **황색 실선 복선**. 한 선 폭 10~15cm, 점선이면 칠 3m/빈 3m | 복선, 선 0.4 · 사이 0.5 |
| 차선(503) | 같은 방향 차로 경계 = **백색 점선** | 점선 칠 6 · 빈 6 (현재) |
| 진로변경제한선(506) | 편도 2차로 이상, **정지선에서 50m 이내**는 백색 **실선** | 정지선 앞 약 40스터드를 실선으로 |
| 버스전용차로(504) | 편도 3차로 이상, 청색 | 현재 청색 단선 |
| 정지선(530) | 백색 실선, 폭 **30~60cm**(도심 30~45cm), 정지 지점 **2~5m 앞**(원칙 2~3m) | 폭 1.2, 횡단보도에서 6~9 떨어뜨림 |
| 횡단보도(532) | 지브라식 백색, 폭 **최소 4m**, 넘으면 2m 단위로 넓힘, 6m 이상이면 가운데로 나눔. 편도 3차로 이상은 가운데 안전지대 권장 | 폭 12(현재 8 → 넓혀야 함) |
| 정차금지지대(524) | 교차로 중앙 구획, 테두리 + 빗금 | 사각 테두리 + 안쪽 짧은 사선(현재) |
| 안전지대(531) | 황색 빗금, 차선·중앙선 연장선에 테이퍼, **모서리 곡선** | 현재 사각 → 끝을 뾰족하게(테이퍼) |
| 유도선(525) | 교차로 안 **백색 점선**(칠·빈 각 50~100cm), 화살표 길이 = 칠 길이 4배(200~400cm). 좌회전이 여러 차로여도 **1개만** 권장 | 좌회전 경로 점선 칠 2 · 빈 2, 사거리 안 곡선 |
| 진행방향 화살표(537~541) | 정지선에서 **2~3m 앞**, 차로 가운데. 추가는 **25m 간격** | 정지선 뒤 8, 다음 80 간격 |
| 횡단보도 예고(529) | 다이아몬드(◇), 횡단보도 50~60m 전, 각 차로마다 | 정지선 뒤 약 160 |

## 지금 맵과 다른 점(고칠 것)
1. 횡단보도 폭 8 → **12** (4m).
2. 정지선을 횡단보도에서 조금 더 떨어뜨리고 폭 1.2로.
3. 정지선 앞 구간 차선을 **실선(진로변경제한선)**으로.
4. 사거리 안 **좌회전 유도선**(백색 점선 곡선) 추가.
5. 중앙 안전지대 끝을 테이퍼로, 횡단보도 예고 ◇ 추가.
6. 정차금지지대는 황색 유지(사용자 사진 기준).
