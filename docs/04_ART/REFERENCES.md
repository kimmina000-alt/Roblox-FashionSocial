# 사용자 레퍼런스 모음 (아트 방향의 기준)

기준일: 2026-10-22 · 결정 D-102

## 아트 방향 (사용자 결정 2026-10-22)
**사용자가 보낸 사진·동영상을 보고 최대한 현실적으로 구현한다.** 한국적 / 글로벌 판타지 / 팝 스테이지 중 하나를 고르는 무드보드 비교는 하지 않는다. 각 공간은 실제 장소·실제 매장을 참고해 만든다.
- 새 공간을 만들거나 바꿀 때는 먼저 이 문서의 레퍼런스를 확인하고, 없으면 사용자에게 레퍼런스를 요청한다.
- 사용자가 새 사진·동영상을 보내면 이 폴더(`docs/04_ART/references/`)에 저장하고 아래 표에 한 줄 추가한다(동영상은 프레임 모음 이미지로).
- Creator Store 에셋을 쓸 때는 후보를 먼저 보여 주고 고르게 한다(D-082).
