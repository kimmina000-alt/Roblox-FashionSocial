# ChatGPT 썸네일 프롬프트 (2026-11-02, D-743)

레퍼런스(클럽·댄스 게임 상위 썸네일)는 모두 AI 일러스트예요. 공통점:
- 로블록스 캐릭터 모양(블록 몸·작은 얼굴)은 그대로, 조명·질감은 3D 렌더처럼
- 밤 + 네온, 레이저, 연기, 반사, 배경 흐림
- 캐릭터가 화면의 반 이상, 큰 춤 동작, 아래에서 올려다보는 각도

쓰는 법
1. ChatGPT에 아래 프롬프트를 그대로 붙여 넣어요. 모델 참고 사진(docs/04_ART/thumbnails/models/)이 있으면 같이 올려요.
2. 글자는 넣지 말라고 해 두었어요. 로고와 문구는 tools/thumbnail/compose_thumb.ps1로 정확하게 올려요(AI는 한글을 자주 틀려요).
3. 가로 썸네일은 1536×1024로 나와요. 합성 도구가 1920×1080으로 잘라서 키워요(위아래 조금 잘려요. 그래서 중요한 건 가운데에 두라고 적었어요).
4. 마음에 안 들면 같은 대화에서 "캐릭터 더 크게", "조명 더 핑크" 식으로 고쳐 달라고 하면 돼요.

---

## ① 메인 썸네일: 클럽 (가로)

```
로블록스 게임 썸네일을 그려 줘. 가로 16:9(1536x1024), 고퀄리티 3D 렌더 일러스트 스타일.

장면: 밤의 한국 홍대 느낌 네온 클럽 "OHU CLUB" 안. 뒤쪽 가운데에 DJ 부스(턴테이블 두 대, 핑크·시안 네온 라인), 그 뒤로 거대한 LED 벽에 음악 이퀄라이저 막대가 빛나. 천장에서 보라·핑크·시안 레이저가 쏟아지고, 바닥은 빛나는 네온 댄스 플로어, 공기 중에 옅은 연기와 반짝이 파티클.

캐릭터: 로블록스 아바타 4명(로블록스 특유의 블록 몸과 작은 얼굴 비율 유지)이 앞쪽에서 신나게 춤춰. 화면의 60% 이상을 캐릭터가 차지하게 크게.
- 왼쪽: 검은 고딕 니트 비니, 검은 레이싱 재킷, 줄무늬 반바지, 은색 피어싱 — 힙합 동작으로 한 팔을 앞으로 내밀어.
- 가운데 왼쪽: 고양이 귀 헬멧, 검은 단발 + 포니테일, 검은 크롭 니트, 그라피티 청반바지 — 브이 포즈로 점프.
- 가운데 오른쪽(주인공, 제일 크게): 연한 금발 곱슬머리에 쥐 귀, 핑크·하늘 파스텔 튜튜 스커트, 핑크 줄무늬 재킷, 별 스니커즈 — 한 손을 높이 들고 웃으며 춤춰.
- 오른쪽: 검은 땋은 머리, 검정·핑크 집업, 에모 튜튜 스커트, 하얀 레이스 토끼 안대 — 윙크하며 웨이브.

구도: 살짝 아래에서 올려다보는 다이내믹한 앵글, 캐릭터들은 카메라를 보며 웃는 표정. 테두리에 핑크·보라 림라이트, 배경은 살짝 흐리게(피사계 심도).
위쪽 25%는 비교적 어둡고 단순하게 비워 둬(나중에 로고를 넣을 자리), 아래쪽 15%도 어둡게(문구 자리).
색감: 핫핑크, 보라, 시안 네온. 아주 선명하고 채도 높게.
중요: 이미지 안에 글자·로고·숫자를 절대 넣지 마.
```

## ② 패션 썸네일 (가로)

```
로블록스 게임 썸네일, 가로 16:9(1536x1024), 고퀄리티 3D 렌더 일러스트.

장면: 밝은 핑크빛 패션 쇼룸. 큰 전신 거울, 옷걸이 행거에 알록달록한 옷들, 반짝이는 조명과 하트·별 파티클.

캐릭터: 로블록스 아바타 2명(블록 몸·작은 얼굴 비율 유지)이 거울 앞에서 코디를 자랑해.
- 왼쪽: 하얀 Y2K 튜브탑과 스커트, 하얀 고딕 버클 부츠, 은색 클로버 목걸이, 금발 단발, 검은 숄더백 — 손을 허리에 얹고 자신감 있는 모델 포즈.
- 오른쪽: 갈색 양갈래에 고양이 귀, 핑크 메이드풍 원피스, 고양이 꼬리 — 한쪽 다리를 들고 귀여운 포즈.
가운데에 작은 홀로그램 패널들이 떠 있고, 그 안에 옷·신발·모자 아이콘(옷을 갈아입는 느낌).

구도: 캐릭터 두 명이 화면의 65%, 정면에서 살짝 낮은 앵글, 둘 다 카메라를 보며 웃어.
위쪽 25%는 단순하게 비워 둬(로고 자리), 아래 15%도(문구 자리).
색감: 파스텔 핑크, 라벤더, 하얀색, 반짝임.
중요: 이미지 안에 글자·로고·숫자를 절대 넣지 마.
```

## ③ 오후네컷(사진관) 썸네일 (가로)

```
로블록스 게임 썸네일, 가로 16:9(1536x1024), 고퀄리티 3D 렌더 일러스트.

장면: 한국식 네 컷 셀프 사진관 안. 핑크 벽, 링 조명, 머리띠·안경·하트 소품이 걸린 소품 벽. 오른쪽에 막 뽑혀 나온 세로로 긴 네 컷 사진 띠(사진 속에는 같은 친구들이 네 가지 포즈).

캐릭터: 로블록스 아바타 3명(블록 몸·작은 얼굴 비율 유지)이 카메라 앞에서 함께 포즈.
- 하늘색 롱 포니테일에 고양이 우주 헬멧
- 큰 검은 사각 안경, 갈색 머리, 하얀 그래픽 티셔츠
- 은발 웨이브 머리, 베이지 탱크톱, 와이드 청바지, 갈색 반다나
셋이 브이, 하트, 볼 찌르기 포즈를 하며 웃어. 플래시가 터지는 순간처럼 밝은 하이라이트.

구도: 캐릭터가 화면의 60%, 정면 눈높이, 위쪽 25%는 단순하게(로고 자리).
색감: 베이비 핑크, 하얀색, 따뜻한 조명.
중요: 이미지 안에 글자·로고·숫자를 절대 넣지 마(사진 띠에도 글자 없이).
```

## ④ 게임 아이콘 (정사각)

```
로블록스 게임 아이콘, 정사각 1:1(1024x1024), 고퀄리티 3D 렌더 일러스트.

로블록스 아바타 1명(블록 몸·작은 얼굴 비율 유지)의 얼굴과 상반신을 크게: 연한 금발 곱슬머리에 쥐 귀와 핑크·하늘 머리띠, 하늘색 클로버 안경, 핑크 줄무늬 재킷. 윙크하며 브이 포즈.
배경: 핫핑크에서 보라로 가는 그라데이션, 뒤에 흐릿한 네온 레이저와 반짝이.
캐릭터가 화면의 75%를 차지하고, 작게 줄여도 알아볼 수 있게 굵은 윤곽과 강한 대비.
중요: 글자·로고·숫자 없이.
```
