# Art Direction

목표: 패션 아바타가 주인공처럼 보이는 세련되고 아름다운 Social World.

우선순위:
1. Character readability
2. Attractive silhouette
3. Photo composition
4. Consistent style
5. Roblox performance

AI Workflow:
Reference images → Mood/Composition 분석 → World Design → Asset List → AI-assisted asset generation → Studio assembly → Playtest → correction
