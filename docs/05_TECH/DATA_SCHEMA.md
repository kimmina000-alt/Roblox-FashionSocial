# Data Schema

## Player
Platform: Roblox-owned items
Persistent: SavedOutfits, House, Settings, Favorites, Progress
Session: CurrentOutfit, CurrentPlace, RunwayOutfit, ActiveRunway

## House Item
ItemId / Asset reference / Position / Rotation / Scale if supported / PlacementType / customization

## Runway Session
SessionId / PlayerId / Theme / RoundState / validated appearance snapshot / voting / rewards
