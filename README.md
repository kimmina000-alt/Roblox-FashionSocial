# Roblox Fashion Social Game — Documentation

이 폴더가 게임 기획의 Source of Truth다.

- `GAME_MASTER.md` — 전체 게임 핵심 규칙
- `00_PROJECT/` — 비전, 코어 루프, 원칙, 로드맵
- `01_SYSTEMS/` — 기능별 설계
- `02_WORLDS/` — 구역별 설계
- `03_CONTENT/` — 콘텐츠/에셋
- `04_ART/` — 아트 방향/레퍼런스
- `05_TECH/` — 기술 구조/API/데이터/보안
- `06_LOG/` — 결정/변경/이슈

원칙: `SYSTEMS`는 무엇을 하는가, `WORLDS`는 어디에서 경험하는가를 정의한다.
